第一次連線(一次性):
  1. 在 Apps Script「排程項目同步」專案:部署 → 管理部署作業,複製「網頁應用程式」網址,貼到上方。
  2. 執行 showAccessToken,從執行記錄複製存取金鑰,貼到上方,按「連線」。
  3. 連上後下方會出現同步碼(網址 + 金鑰打包成一串)。
把同步碼存到手機(或私人記事)。這台還原機重開機後,回到本頁把同步碼貼進最下方欄位,按「連線」即可還原全部資料。
⚠ 同步碼就是資料的鑰匙,只給需要使用的人。懷疑外洩時,到 Apps Script 執行 rotateAccessToken 換新金鑰,再把新金鑰更新到網站與 GitHub Secret GAS_TOKEN。
