你的同步碼 — 存到手機,下次貼上即可還原
取得 Master Key(一次性,約 1 分鐘):
  1. 到 jsonbin.io 免費註冊並登入。
  2. 進入 API Keys,複製 X-MASTER-KEY 貼到上方。
  3. Bin ID 留空,按「連線 / 建立」→ 系統自動建立資料庫並給你同步碼。
把同步碼存到手機(或私人記事)。這台還原機重開機後,回到本頁把同步碼貼進最下方欄位,按「連線」即可還原全部資料。
